Symbol Preview

Live preview from dist/svg/

Usage: Open this file from the repo root in a browser — open preview.html or drag into browser. Images load from dist/svg/ (flat-badge, flat-nobadge, flat-nobadge-dark). Run npm run build first if dist/ is empty, then refresh.

Variant selection: Use flat-badge on any background (sparse maps). Use flat-nobadge on light/terrain tiles and flat-nobadge-dark on dark/satellite tiles (dense maps). Select based on user's badge preference + system color mode.
